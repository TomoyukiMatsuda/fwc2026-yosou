# やりたいこと
2026 FIFA W杯のグループリーグからトーナメント、優勝予想まで簡単にできるアプリケーションを個人開発したい
友人と一緒に盛り上がれるレベルのアプリを想定
# できること
- グループリーグ勝ち抜き予想（1位2位）
- トーナメント勝ち抜き予想から優勝まで各順位予想
- 回答していくと次の予想質問が出てきて順々に回答をしていくと全ての予想が簡潔する
- ログインしなくても予想した結果を他者に共有できる（PDF or URL を想定）
## 留意事項
ログインせずにどのようにデータを共有するか
ブラウザ機能（ローカルストレージなど）を利用して最低限のデータをユーザーに保持させる
